A free mobile-first PWA for managing event budgets (weddings, etc.) so a small group of family members can collaborate on a shared expense list and a separate plan/forecast.

Stack: React + Vite + TypeScript + Tailwind v4 · Supabase (Postgres + Auth + RLS) · GitHub Pages. Zero-cost operation on Supabase's free tier.
